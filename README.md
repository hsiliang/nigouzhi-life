# 你購置的人生

十個網友搬進同一棟快被拆的老大樓，一起過日子的惡搞模擬人生。手機和電腦的瀏覽器都能玩，存檔留在你自己的裝置上。

**開始玩：** <https://hsiliang.github.io/nigouzhi-life/>

## 玩法

選一位朋友當主角，每天分早、午、晚三個時段，點房間做事。完成當日目標拿星星，每章累積 9 顆才能往下走，全遊戲 8 章 40 天。

- 上班摸魚時按「老闆來了」或 Esc，畫面會變成假 Excel 並靜音。
- 嫉妒值爆表會引發大亂鬥，投訴值爆表大樓會被封。
- 判斷新租客是不是騙子，調解鄰居冷戰，每位主角有自己的結局。
- 設定裡可以切換繁體和简体，也能用存檔碼在手機和電腦之間搬存檔。

## 開發

```sh
npm install
npm run dev     # 開發伺服器
npm test        # 單元與內容測試
npm run e2e     # 瀏覽器測試
```

`tools/` 放素材腳本：人物圖去背、語音產生、繁簡對照、字型子集化。人物原圖不在 repo 裡。

## 素材來源

- 字型：[jf open 粉圓](https://github.com/justfont/open-huninn-font)、[站酷快樂體](https://github.com/googlefonts/zcool-kuaile)，皆為 SIL OFL，授權檔在 `public/fonts/`。
- 語音：透過 `edge-tts` 使用 Microsoft 神經語音產生，僅供朋友間非商業使用。
- 音樂與音效：由程式即時合成。
- 人物形象：朋友們的 AI 繪製形象，僅供本遊戲使用。

遊戲內容純屬朋友間的玩笑與虛構，非商業用途。
