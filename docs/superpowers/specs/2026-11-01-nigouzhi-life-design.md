## 1. 這是什麼

10 個好朋友當主角的惡搞版模擬人生。玩家搬進同一棟老大樓，和朋友們面對面過日子，用上班摸魚的零碎時間一天一天玩下去。

【你定】現實中這 10 人是同一個聊天群的網友。遊戲把群裡真實遇過的三大挑戰（被封群、新網友亂入、內部鬧矛盾）變成大樓裡的鄰里危機，玩的人會認出這是在演自己的群。

成功的樣子：朋友打開遊戲看到自己，先笑著罵一句「你購置的」，再把截圖丟回群裡，玩到結局時覺得有點感動。

標註說明：**【你定】** 是你明確說的；**【我定】** 是我的提案，你可以推翻。

## 2. 目標、不做的事、絕對不能犯的錯

### 目標
- 【你定】單機、手機和電腦都能玩。
- 【你定】風格是嫉妒、極度搞笑、惡搞、可愛又溫馨，適合打發上班時間。
- 【你定】使用 `Roles/` 裡的 10 位人物形象。
- 【你定】所有人在同一個地方面對面互動，成都、南京等地都只當老家。
- 【你定】聲音用 AI 添加。
- 【你定】無法在一小時內通過所有關卡。
- 【你定】用 git 管理，同步到 GitHub public repo。

### 不做的事
- 不做連線、帳號、伺服器、排行榜和內購。
- 不做 3D。
- 不做高自由度的建造和裝潢，模擬人生的成分集中在日程、狀態、人際和事件。

### 絕對不能犯的錯
- 把朋友的真實痛處當笑點：壯壯單親養家、豆豆單身、任何人的備孕結果和婚姻，都不能拿來羞辱。可以調侃行為，不嘲笑處境。壯壯的辛苦走溫馨線。
- 內容露骨。這是 public repo，兩性話題只到嘴砲和暗示。桃叔裸奔一律用大桃子遮住，只做卡通化處理。
- 出現真實姓名、公司、住址或任何能認出本人的資料。遊戲裡只用暱稱。
- 重現真實吵架。遊戲裡的冷戰起因全部虛構且無傷大雅，例如外賣被吃掉，不影射任何真實矛盾。
- 親密行為出現在畫面上。一律只用牆壁震動、噪音分貝計和鄰居便條暗示。
- 上班時突然大聲出聲，或點開就要玩很久才能存檔。
- 非本遊戲人物（老登、光哥老婆、卡卡女友、人老師）有形象或被具體描寫。他們只存在於台詞，人老師只有豆豆在罵，不補任何真實細節。

## 4. 世界觀與玩法

### 舞台【我定】
壯壯發起「購置大樓」合租計畫，10 人搬進同一棟老大樓。工作地點也塞進大樓，畫面是模擬人生式的剖面娃娃屋。

- 1 樓：中庭、湯圓的診所、壯壯的倉庫
- 2 樓：卡卡的健身房、瑤老師的美術教室、大姨的 CAD 工作室兼網咖
- 3 樓：光哥的實驗室、豆豆的工廠辦公室
- 4 樓：貝貝的智慧豪宅
- 屋頂：桃叔的 AI 工作室、光哥拍夕陽的位置
- 隔壁：派出所（桃叔失蹤時會在這）

### 主角【我定】
開局從 10 人中任選 1 位，所有朋友都能玩自己。主線相同，每人有專屬技能、專屬對白和個人結局。破關後可換人再玩，圖鑑進度保留。

### 一天的流程
1. 一天就是一關，分早、午、晚 3 個時段，每天有當日任務。
2. 每個時段在剖面圖點一個房間，移動過去，選擇和人聊天、工作、休息或進行迷你遊戲。
3. 動作影響精力、心情、購置幣、對每位朋友的好感度，以及大樓幸福度。
4. 一天結束時結算 0 到 3 顆星，並隨機出一張朋友圈式的惡搞貼文。

每位 NPC 依時段排班：光哥晚上在實驗室，湯圓幾乎都在診所，胖虎只以低機率現身，桃叔會隨機失蹤幾天，失蹤期間房門貼「人已被帶走」。

### 嫉妒系統
全場有一條**嫉妒值**。卡卡訴苦、貝貝曬照、夫妻秀恩愛都會讓它上升，爆表時觸發「嫉妒大亂鬥」搞笑事件和一場迷你遊戲。大姨、豆豆、貝貝互噴「你購置的」是遊戲的招牌演出。

### 三大鄰里危機（挑戰來自你，規則【我定】）

**危機一：封樓（對應被封群）**
- 大樓有一條**投訴值**。公共場所聊尺度太大、半夜備孕吵到鄰居、桃叔光屁股上街，都會讓它上升。
- 投訴值高時，先收到鄰居便條和里長警告，再來是警察上門帶人，被帶走的人會消失幾天。
- 投訴值爆表時大樓被貼封條，損失一天並扣幸福度。壯壯帶大家從後門搬進新樓，樓名變成「購置大樓 2 號」，再封就變 3 號，對應封群後重建新群，玩家的封樓次數會變成成就。
- 降低投訴值的方法：提醒大家小聲、送鄰居伴手禮、打掃公共區域。

**危機二：新租客（對應新網友）**
- 不定期有新租客搬入，他們是虛構的路人，用 SVG 簡筆造型，不使用真實人物。
- 類型：潛水型（搬來後從不說話）、廣告型（敲門賣保健品和微商）、詐騙型（帶單投資、假富婆、中獎通知）、正常型。
- 玩家看對話線索，找桃叔鑑定或問湯圓、貝貝意見，最後由群主壯壯決定歡迎、觀察或移出大樓。
- 趕走壞租客有獎勵，放任詐騙型會損失大家的購置幣和幸福度，錯趕好人也會扣分。

**危機三：鄰里冷戰（對應內部鬧矛盾）**
- 由主線或隨機事件觸發，兩位朋友互不理睬，不待在同一房間；同框時改用背面圖背對背站。
- 冷戰期間兩人的相關事件暫停，幸福度每天下降。
- 玩家要分別聽兩邊說法，再用傳話、送對方喜歡的東西或約到屋頂看夕陽來調解，完成後播放和好演出。

### 上班摸魚設計【我定】
- **老闆鍵**：畫面右上角按鈕或電腦按 `Esc`，立刻切換成假 Excel 報表並靜音，再按一次回來。
- **首次啟動問「你現在在上班嗎？」**，答是就全程靜音。
- 每個動作自動存檔，關掉再開從當下繼續。
- 全程只用點擊，不需要打字或長時間專注。
- 一天約 2 到 3 分鐘，可以隨時中斷。

## 5. 關卡規模

- 【我定】8 章，每章 5 天，共 40 關。
- 每章累積 9 顆星以上才能進下一章；沒過關不會 Game Over，只是重玩當天，並有吐槽台詞。
- 目標：第一次全破至少 65 分鐘，一般約 100 到 120 分鐘。
- 內容量目標：主線文字至少 14,000 字；每位 NPC 閒聊至少 30 句；隨機事件至少 80 則；10 個個人結局各至少 300 字；新租客至少 12 位；冷戰組合至少 8 組。

## 6. 劇情【我定，含劇透】

故事開頭，大樓門口貼出拆遷通知，一個月後要拆。豆豆咬定是人老師搞的鬼。大家決定把大樓幸福度衝到滿，向「購置集團」證明這裡不能拆。

| 章 | 標題 | 內容 |
|---|---|---|
| 1 | 搬家了你購置的 | 教學，認識所有人，通知出現 |
| 2 | 光哥今晚也加班 | 光哥躲老婆，大家幫忙圓謊；第一張鄰居便條，教學投訴值 |
| 3 | 卡卡保衛戰 | 豆豆調戲升級，卡卡訴苦引爆嫉妒；第一位廣告型租客，教學移出大樓 |
| 4 | 備孕大作戰 | 大姨和湯圓請教胖虎，半夜噪音引來投訴，第一次封樓，搬進 2 號樓 |
| 5 | 桃叔不見了 | 桃叔被抓走，大家才發現多依賴他；沒人鑑定時潛水型租客讓全樓疑神疑鬼 |
| 6 | 誰是最強炫富 | 貝貝的豪宅派對，三人組互噴過火，第一次冷戰 |
| 7 | 瑤老師瘦了嗎 | 全棟陪跳繩，胖虎的不安引發夫妻小冷戰，大家出手調解 |
| 8 | 群主的生日 | 詐騙型租客假扮購置集團收「安置金」，全員聯手拆穿；拆遷最終倒數與結局 |

**結局反轉**：拆遷通知是桃叔用 AI 做的假圖。他發現壯壯已經很久沒休假，想用這招逼大家聚在一起，幫壯壯過一次像樣的生日，結果還來不及講就被警察帶走，整件事失控，連詐騙租客都拿這張假通知來騙錢。真相揭開後大家一起罵他「你購置的」，再把生日辦成大樓派對，壯壯終於下班一次。

**溫馨彩蛋**：光哥手機裡全是夕陽，原來每天都傳給老婆，假裝加班的人其實一直在報平安。瑤老師的體重最後依然不變，胖虎說這樣剛好。

備孕線不交代任何人懷孕成功或失敗，以大家互相打氣收尾。

## 7. 美術

- 【我定】從每張設定圖裁出正面、側面、背面，去背後做成貼紙風人物，加統一白邊，讓水彩和向量等不同畫風放在一起也和諧。
- 正面用於待機和對話，側面左右翻轉用於行走，背面用於離開。
- 表情差分用疊加貼圖（汗滴、愛心、怒氣、黑線）和彈跳動畫完成。
- 目前沒有 Gemini 或其他繪圖 API key，所以不會新增人物姿勢。場景、道具和 UI 由我用 SVG 手繪風格製作。
- 光哥的圖有夕陽背景，需要較強的去背工具 `rembg`，其餘可用簡單背景去除。
- 光哥圖上的手寫簽名和日期處理時全部移除，避免疑似真名進入 public repo。
- 貝貝圖上的「ok」保留，當成人物的一部分。

## 8. 聲音

- 【我定】語音用 Microsoft 神經語音（`edge-tts`）預先產生音檔，10 人各配不同聲線。桃叔用台灣腔；大姨、壯壯、貝貝、豆豆若有可用的四川或西南聲線就用，沒有就用普通話。湯圓試粵語聲線。
- 語音只配招牌台詞和關鍵演出，每人 10 到 15 句，約 100 到 150 句。其餘對話用可愛的咕嚕音。
- 音樂和音效：目前沒有 AI 音樂 API key，由我用程式合成，檔案輕量、無授權問題。這部分不算嚴格的 AI 生成音樂。
- `edge-tts` 是非官方工具，Microsoft 服務的輸出用於 public repo 有條款疑慮。僅限朋友間非商業使用；若不想承擔，可改用開放授權的模型，但音質會明顯下降。
- 開關：語音、音樂、音效各自獨立。

## 9. 技術與發佈

- 【我定】網頁遊戲，TypeScript + Vite，不用大型遊戲引擎，執行時不載入任何外部 CDN 或 Google Fonts，全部資源打包在專案內。
- 版面響應式：手機直向優先，電腦以置中手機框加大版呈現。
- 存檔用 `localStorage`，附「存檔碼」可在手機和電腦間手動轉移。
- 語言：內容以繁體撰寫，打包時用 OpenCC 轉簡體；首次依瀏覽器語言自動選擇，遊戲內可切換。
- 【你定】git + GitHub public repo。【我定】repo 名 `nigouzhi-life`，放在你的 `hsiliang` 帳號，由 GitHub Actions 部署到 GitHub Pages，網址為 `https://hsiliang.github.io/nigouzhi-life/`。
- `Roles/` 原圖不進 repo，只提交處理後的貼圖。人物圖、裁切設定、去背腳本分開管理。

### 已知風險
1. **GitHub Pages 在中國大陸可能連不上或很慢**，而多數朋友在大陸。上線後要找一位朋友實測；連不上時的備案是打包一個可直接開啟的離線版。
2. **public repo 任何人都看得到**，包含暱稱、人物圖和惡搞內容。設計上只放暱稱，但朋友圈內的人仍認得出彼此。
3. 洋基標誌、貓咪形象和「王者榮耀」等第三方元素只限非商業自用。迷你遊戲不使用原遊戲素材。
